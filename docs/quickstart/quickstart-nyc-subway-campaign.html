OPEN DESIGN

The terminal in your pocket is now a design studio.

IDMO Four lines · Install · Design · Modes · Operate. Ride them in order.

The Brief

Get a developer from prompt to working prototype before the next stop.

Open Design is local-first. It drives the coding agent already installed on your machine — Claude Code, Codex, Gemini, OpenCode, Cursor Agent, Qwen, Devin, Copilot — and turns one sentence into a live, sandboxed HTML design you can save to disk. No cloud account. No blank canvas.

No agent installed? Drop in a BYOK API key and the same loop runs against Anthropic, OpenAI, Azure, or Gemini.

The Idea

You type.
It builds.
You save.

A single prompt → an agent streams → one <artifact> is parsed out → it renders live → “Save to disk.” Five beats, every time.

Line I · Install · stop 1

What you bring aboard

Node 22 won’t board — package.json#engines pins ~24. If the daemon can’t see a CLI you installed, its folder isn’t on the daemon process’s PATH; fix it, then hit Rescan in Settings → Execution mode.

Line I · Install · stop 2

Two commands.
Pick your lane.

Dev mode runs daemon + web in the foreground. The bare command runs all three — daemon, web, desktop — in the background. Or skip Node entirely with Docker.

One rule: pnpm tools-dev is the only lifecycle entry point. Legacy pnpm dev / pnpm start were removed on purpose.

Platform wall takeover · Line D · Design

Type a prompt. Watch it design itself.
  • 1App auto-detects your CLI, defaults to the web-prototype skill + Neutral Modern system.
  • 2Pick a Skill (Prototype · Deck · Template · Design-system) and a Design system — 129 ship in the box.
  • 3Type what you want, hit Send. Tokens stream left; the artifact renders live in a sandboxed iframe on the right.
  • 4Click Save to disk → ./.od/artifacts/<ts>-<slug>/index.html.

Line M · Modes

Two ways to reach a model.

Local CLI is the default the app picks when it finds an agent:
frontend → daemon /api/chat → spawn(agent) → SSE → artifact → preview.

API (BYOK) is the fallback — Anthropic, OpenAI, Azure, Gemini:
frontend → /api/proxy/{provider}/stream → SSE → artifact → preview.

Both feed the same artifact parser and the same sandboxed iframe. Only the transport differs.
