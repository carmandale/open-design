00 · The intangiblesDecide before you draw

Search for the meaning first.

Open Design drives the coding agent already on your machine — Claude Code, Codex, Gemini, OpenCode, Cursor Agent, Qwen, Devin, Copilot — or a BYOK API key, and turns one sentence into a live, sandboxed design you save to disk. This guide is set the way Vignelli would set it: nothing decorative, the white space carrying the hierarchy.

Semantics

A blank canvas is the enemy. The job is to get from intent to a working artifact with the least ceremony.

Appropriateness

Local-first, terminal-native. The tool meets the developer where the work already lives — the repo, the CLI.

Timelessness

One lifecycle entry point. One artifact contract. Primary structure that outlasts any one model or agent.

03 · Line I · runTwo commands either way

Get it running.

Dev — foreground

# from the repo root
corepack enable
pnpm install
pnpm tools-dev run web
# open the URL it prints

# …or all three in background
pnpm tools-dev

Docker — no node / pnpm

cd deploy
cp .env.example .env
openssl rand -hex 32
# paste into OD_API_TOKEN
docker compose up -d
# http://localhost:7456

One rule, no exceptions. pnpm tools-dev is the only lifecycle entry point. The legacy pnpm dev / pnpm start aliases were removed by design — equity of the system over the convenience of the moment.

04 · Line D · designYour first artifact

Type a prompt. Save the result.

  1. Auto-detect. On first load the app finds your agent CLI and defaults to the web-prototype skill + the Neutral Modern design system.
  2. Choose the stack. In the top bar pick a Skill (Prototype · Deck · Template · Design-system) and a Design system — 129 ship in the box: 2 starters, 70 product systems, 57 design skills.
  3. Send. Type the prompt and submit. Tokens stream into the left pane; the parsed <artifact> renders live in a sandboxed iframe on the right.
  4. Persist. Click Save to disk → ./.od/artifacts/<ts>-<slug>/index.html.

The prompt is composed in three layers: BASE_SYSTEM_PROMPT + the active design system (DESIGN.md) + the active skill (SKILL.md). Swap either in the top bar and the next send uses the new stack.

05 · Line M · modesTwo ways to reach a model

One canvas. Either engine.

Local CLI — default

The path Open Design picks when it detects an installed agent. No key to paste.

frontend → daemon /api/chat
→ spawn(<agent>) → stdout
→ SSE → artifact → preview

API — BYOK fallback

Anthropic · OpenAI · Azure OpenAI · Google Gemini. Used when no CLI is present, or by preference.

frontend → daemon /api/proxy/{provider}/stream
→ normalized SSE
→ artifact → preview

Both feed the same artifact parser and the same sandboxed iframe. Only the transport differs — local CLIs fold the system prompt into the user message because they have no separate system channel.
